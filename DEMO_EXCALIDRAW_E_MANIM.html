Comparando elementos: QuickSort

Como 15 Linhas de Python Criam Este Vídeo Viral:

O Manim calcula as equações vetoriais de cada barra, círculo e texto. O fundo preto profundo com cores néon cria o efeito visual hipnótico clássico do canal 3Blue1Brown, prendendo o espectador do primeiro ao último segundo do Reel.

from manim import * class QuickSortReels(Scene): def construct(self): # Resolução vertical para TikTok/Reels (9:16) config.pixel_width = 1080 config.pixel_height = 1920 # Cria as barras do vetor de dados valores = [40, 80, 20, 95, 55, 30, 70] barras = VGroup(*[ Rectangle(width=0.6, height=v/25, color=BLUE) for v in valores ]).arrange(RIGHT, buff=0.2) # Animação cinematográfica suave self.play(Create(barras), run_time=1.5) self.play(barras[2].animate.set_color(YELLOW)) # Pivô self.wait(1)
