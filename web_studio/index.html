1. O QUE É PROGRAMAÇÃO?
Dar instruções claras para o computador resolver um problema.
💡 IDEIA CENTRAL
  • Programar é transformar uma ideia em passos que a máquina consegue executar.
🖥️ COMPUTADOR
  • Executa exatamente o que foi escrito.
  • Não entende intenção; segue instruções sem questionar.
{ } CÓDIGO
  • É o conjunto de instruções escritas pelo programador.
    • console.log("Olá, Mundo!");
</> LINGUAGENS
  • Formas de escrever instruções legíveis para humanos e computadores.
  • Exemplos: Python, JavaScript e C++.
⚙️ FLUXO BÁSICO
  • ENTRADA: dados recebidos (teclado, clique, sensores)
  • PROCESSAMENTO: regras de cálculo aplicadas
  • SAÍDA: resultado final exibido na tela
⚠️ PEGADINHAS
  • Instruções ambíguas geram resultados bizarros.
  • Um pequeno erro de caractere trava a execução.
💬 RESUMO EXPRESSO
  • Problema ➔ Passos ➔ Código ➔ Resultado
