5 Desafios Práticos com Código Real

Resolva os problemas do mundo real abaixo. Execute a simulação, estude a mecânica da falha no código e visualize a solução de defesa aplicada pelo time de Blue Team!

MISSÃO 1

Vazamento de Banco de Dados por Injeção SQL

PENDENTE

🎯 Problema Real: Uma API de consulta de usuários concatena strings na query SQL sem sanitização, permitindo que invasores executem comandos UNION SELECT e roubem senhas com hash.

Conceito: Prepared Statements MITRE: T1190 OWASP: A03:2021 Injection
❌ Código Vulnerável:
query = f"SELECT * FROM users WHERE id = {user_input}"
cursor.execute(query) # Concatenação direta!
✅ Defesa Correta (Parameterized Query):
query = "SELECT * FROM users WHERE id = ?"
cursor.execute(query, (user_input,)) # Seguro!
MISSÃO 2

Sequestro de Sessão de Usuário via XSS Refletido

PENDENTE

🎯 Problema Real: A tela de login reflete o parâmetro de URL ?redirect= diretamente no HTML sem sanitização contextual, permitindo que scripts roubem cookies de sessão.

Conceito: HTML Entity Encoding & CSP Flag: HttpOnly Cookies OWASP: A03:2021 Injection
❌ Código Vulnerável:
html = f"<a href='{redirect_url}'>Clique aqui</a>"
return html # Injeta JavaScript arbitrário!
✅ Defesa Correta (Sanitização + HttpOnly):
import html
safe_url = html.escape(redirect_url)
response.set_cookie('session', token, httponly=True, samesite='Strict')
MISSÃO 3

Ataque de Força Bruta & Esgotamento de Recursos

PENDENTE

🎯 Problema Real: O endpoint de autenticação não impõe limites na quantidade de tentativas de login por minuto, permitindo ataques de dicionário com ferramentas como Hydra.

Conceito: Token Bucket / Rate Limiting Defesa: Fail2Ban & WAF Lockout MITRE: T1110
❌ Sem Rate Limit:
def login():
    # Processa login sem checar histórico do IP!
    return verify_password(user, password)
✅ Defesa com Rate Limiting & Bloqueio:
if requests_in_window(client_ip, seconds=60) > 5:
    soar_quarantine_ip(client_ip, duration="15m")
    return Response("Too Many Requests", status=429)
MISSÃO 4

Vazamento de Arquivos Locais (Path Traversal / LFI)

PENDENTE

🎯 Problema Real: Endpoint de download aceita caminhos relativos como ../../../../etc/passwd, permitindo que atacantes leiam arquivos fora da pasta pública do site.

Conceito: Canonicalization & Whitelist MITRE: T1083 OWASP: A01:2021 Broken Access Control
❌ Leitura Direta de Caminho:
filepath = "/var/www/uploads/" + filename
return open(filepath).read() # Aceita ../../../ !
✅ Validação Canônica Segura:
base_dir = os.path.abspath("/var/www/uploads/")
target_path = os.path.abspath(os.path.join(base_dir, filename))
if not target_path.startswith(base_dir):
    raise SecurityException("Path Traversal Bloqueado!")
MISSÃO 5

Reconhecimento Ativo & Mapeamento de Superfície

PENDENTE

🎯 Problema Real: Identificar portas abertas e serviços desnecessários em execução antes que invasores descubram portas vulneráveis.

Conceito: Port Hardening & Firewall MITRE: T1595 Active Scanning
